# Input contract

A, B, C, D; state_units, input_unit, output_unit, model_scope in system. SI units and data_basis are required. This skill transforms a supplied linear model; it does not identify a plant from measurements or derive arbitrary equations from prose.

Keep measured, assumed, derived and synthetic inputs distinct. Supply source references and the operating point/model scope when available. An output inherits the input model limitations; missing data are not inferred as measured values.
