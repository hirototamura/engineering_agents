# Experiment archive

Experiment evidence is organized by project so that historical ECLSS work and
the balancing-cube research remain distinct.

| Folder | Contents |
| --- | --- |
| [`eclss/`](eclss/) | ECLSS campaign archives, analysis tools and data, reports, and run output |
| [`balancing_cube/`](balancing_cube/) | Balancing-cube simulation campaigns and reports |

The files in `experiments/` are research records and analysis assets. Runtime
code belongs under `src/`; generated run output belongs in the matching
project's `results/` directory. Run outputs are ignored by Git except for the
curated ECLSS evaluation catalogue.
