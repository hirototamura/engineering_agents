# シナリオ別の実装ガイド

各シナリオは、世界、要件の出典、許可する介入、証拠、評価を持ちます。プロジェクト内で対等な事例であり、すべてのバックエンド、モード、提案形式、検証の主張を共有するわけではありません。

- [スクラバー劣化](scrubber_degradation/index.md)：モック ECLSS/EPS の復旧、ステップごとのチーム、実行後の設計提案。提案の再適用は未実装です。
- [SSOS ECLSS ループ](ssos_eclss_loop/index.md)：貯蔵系の操作、操作・設計の独立モード、プラントのモデル検査、連鎖した提案適用。
- [バランシングキューブ](balancing_cube/index.md)：版付き SSOT 入力、範囲付きの機械・制御のコンパイル、固定時間刻みの MuJoCo/MJX 評価、専用の設計ワークフロー。

各事例の開発者向け概要から入り、変更に応じて実装または評価へ進みます。公開の前提条件、コマンド、設定、結果の読み方は、対応する[利用者向けシナリオ](../../users/scenarios/index.md)にあります。

共有部分は[実行](../runtime.md)、[保存](../reference/storage.md)、[エージェント](../agents.md)を参照します。別の同梱事例の追加には、現在のレジストリと振り分けへの接続が必要です。[シナリオ追加](../guides/add-scenario.md)を参照してください。外部読み込みは[開発目標](../development/external-scenarios.md)です。
