# シナリオを選ぶ

同梱の各シナリオは、システム、設計空間、操作、指標、検証の限界を持つ独立した実例です。調べたい問いに合わせて選びます。

## スクラバー劣化

[スクラバー劣化](scrubber_degradation/index.md)は、小さなステーションモデルで CO₂ スクラバー劣化への回復操作を扱います。エージェントなし、ラベル付きルール、LLM を比較し、CO₂ と電力余裕の回復を確認します。実行後の設計推奨は出力しますが、次回シミュレーションへ自動適用しません。

## ECLSS の運用と容量設計

[ECLSS ループ](ssos_eclss_loop/index.md)は空気再生、酸素生成、水再生を操作します。ローカル mock、ローカルプラントモデル、ROS2 SSOS を選べます。提案の適用と設計連鎖に対応し、プラントモデルで生存・資源・コスト・質量を評価します。

## バランシングキューブ

[バランシングキューブ](balancing_cube/index.md)は凍結した One Piece 要求に対して機械設計を評価します。候補スクリーニング、CPU/GPU の数値検証、任意の Isaac キャンペーンを分けます。既存 SSOT ストアと追加依存が必要です。実機の妥当性評価は、実装済みの証拠範囲外です。

[クイックスタート](../quickstart.md)は、ローカルの設計引き渡しを示すため ECLSS mock を選んでいます。別分野の実装は[開発者向けシナリオ追加手順](../../developers/guides/add-scenario.md)に進みます。外部シナリオ読み込みは未実装です。
