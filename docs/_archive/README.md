# Research archive / 研究アーカイブ

Historical research, specifications, plans, and review evidence captured from the
working tree during the documentation rebuild. These are records of their stated
conditions, not current user or developer instructions. They are excluded from
the normal MkDocs site and search. Use `../en/users/`, `../ja/users/`,
`../en/developers/`, or `../ja/developers/` for maintained guidance.

過去の実験条件・測定値・数式・コード例と証拠への参照を保持しています。
資料に書かれた「現在」「完了」「未実装」は、その資料の時点の記述です。
英日両方の原資料がある場合は両方を残し、存在しない翻訳は追加しません。
一部の開発履歴・実験設定は以前の文書再構成でまとめた記録です。

The source paths below identify the material before this rebuild; they are not
compatibility routes. Link destinations were rebased without changing recorded
code blocks or measurements. Local-only evidence links remain local-only.
